# 智慧圖書館管理作業系統 (Smart Library OS)

一個專為圖書館現代化借還流通、藏書編目、讀者管理與**自習室座位預約**打造的 Web 整合作業系統。

---

## ✨ 核心功能特色

1. **📊 視覺化總覽儀表板 (Dashboard)**
   - 全館館藏總量、在庫可借量、借出流通中、逾期未還警示即時統計。
   - 自習室與閱覽席位即時空閒／使用／預約狀態橫幅。
   - Chart.js 圓餅圖：館藏分類比例分佈（資訊、心理、文學、歷史等）。
   - Chart.js 長條圖：館藏借閱與在館健康度分析。
   - 近期借閱動態即時清單與快速歸還。

2. **🪑 自習座位預約系統 (Seat Reservation System) 【全新功能】**
   - **分區座位管理**：
     - 🎧 **A區 靜音自習區**（個人專屬插座、檯燈、靜音環境）
     - 💻 **B區 電腦檢索區**（雙螢幕、電子資料庫檢索、論文編修）
     - 👥 **C區 研討與多功能區**（小組研討室、投影螢幕、會議設備）
   - **互動平面圖**：直觀視覺化座位狀態（🟢 空閒、🔴 使用中、🟡 已預約）。
   - **智能時段防撞機制**：自動檢核同時段重複預約與個人時段衝突。
   - **完整流通生命週期**：讀者預約 ➔ 現場報到簽到 ➔ 提前簽退釋放 ➔ 取消預約。

3. **🔄 借還書作業工作台 (Circulation Desk)**
   - **圖書借出登記**：智能連動讀者借閱額度與在架庫存，具備防呆機制（借書達上限、讀者停權或尚有逾期者限制借閱）。
   - **快速歸還**：即時搜尋借閱紀錄，一鍵點擊完成還書。
   - **線上續借**：未逾期書籍支援一鍵續借延長天數（預設上限 2 次）。
   - **逾期稽催與滯納金計算**：超過應還日期自動標註紅色警報，精準計算逾期天數與罰金。

4. **📖 藏書管理 (Book Catalogue)**
   - 圖書卡片化展示，涵蓋書名、作者、出版社、ISBN、館藏架號與摘要簡介。
   - 即時關鍵字搜尋與分類篩選。
   - 庫存即時動態條（在庫 / 總藏比例視覺化）。
   - 完整的新增、編輯修改、刪除（具備防呆機制：借出中不可刪除）。

5. **👥 讀者借閱證管理 (Member Management)**
   - 區分「學生」、「教職員」、「一般讀者」不同借書上限額度。
   - 即時進度條顯示每位讀者「當前借閱本數 / 最大額度」。
   - 支援讀者狀態管理（正常借閱 / 停權暫停使用）。

6. **📋 借閱紀錄檢索與報表匯出 (Loan History & Export)**
   - 完整紀錄追蹤（所有、借閱中、逾期未還、已歸還）。
   - **支援一鍵匯出 CSV 報表**（包含 UTF-8 BOM，Excel 開啟不亂碼）。

7. **⚙️ 系統參數設定 (Settings)**
   - 自訂預設借閱天數（如 14 天）。
   - 自訂逾期每日滯納金（如每日 NT$ 5 元）。

## 🚀 快速啟動方式

### 方法一：雙擊捷徑啟動（最簡單，推薦）
直接在此專案資料夾中，滑鼠雙擊 **`start.bat`** 或 **`啟動系統.bat`**：
- 系統會自動檢查並安裝 Node.js 相依套件 (`node_modules`)。
- 自動啟動後端 Express 伺服器並自動在瀏覽器開啟 `http://localhost:3000`！

### 方法二：命令列啟動
在終端機（PowerShell / CMD）中執行：
```bash
npm install   # 初次使用請先安裝套件
npm start     # 啟動系統
```
伺服器啟動後，使用瀏覽器打開：
👉 **http://localhost:3000**

> 💡 **注意事項**：本系統為 Node.js 全端 Web 應用程式，若直接點擊 `index.html`（`file://` 協議），僅提供介面離線預覽功能。借還書、預約席位與資料儲存需透過上述方法啟動後端伺服器！
